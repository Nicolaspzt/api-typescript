Comando utilizados para iniciar este projeto:

npm init -y
npm i express dotenv
npm i typescript ts-node nodemon @type/express @types/dotenv -D
npx tsc --init

Arquivos criados no início do projeto:
.gitignore -> conteudo: node_modules .env e dist/
.env

Pastas criadas no início do projeto:
dist
src

---

Para rodar um script criado no package.json usar o comando:
npm run SCRIPT
